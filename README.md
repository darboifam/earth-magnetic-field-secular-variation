# Mathematical Modeling and Secular Variation of Earth's Magnetic Field

Independent study project completed at Montgomery County Community College.

This project uses historical NOAA north and south magnetic-pole data from 1590 through 2025 to model changes in Earth's magnetic field over time.

## Files

- `northpole.dat` - NOAA north magnetic-pole data
- `southpole.dat` - NOAA south magnetic-pole data
- `Independent_Study_Project.nb` - Wolfram Mathematica analysis and visualizations
- `Magnetic_Field_Independent_Study_Report.pdf` - Final technical report

## Project Summary

The project converts magnetic-pole latitude and longitude data into Cartesian coordinates, builds a geometric magnetic-moment model, and analyzes changes in magnitude, direction, pole motion, and secular variation over time.

The analysis was completed in Wolfram Mathematica and documented in a LaTeX technical report.
